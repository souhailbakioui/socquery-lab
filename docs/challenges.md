# 🧪 SOC Challenges

## Overview

SocQuery Lab includes progressive challenges designed to develop practical cybersecurity investigation skills.

The challenges move from fundamental querying toward more advanced investigation workflows.

---

# 🟢 Beginner

Beginner challenges focus on:

* Understanding security logs
* Searching events
* Filtering results
* Exploring fields
* Identifying basic suspicious activity

---

# 🟡 Intermediate

Intermediate challenges introduce:

* Aggregation
* Event correlation
* Detection logic
* Suspicious patterns
* Multi-source analysis

---

# 🔴 Advanced

Advanced challenges focus on:

* Complex query pipelines
* Threat hunting
* Detection engineering
* Multi-stage investigations
* Advanced correlation

---

# Progressive Learning

Challenges are designed to support learning through:

```text
Objective
    ↓
Investigation
    ↓
Hint
    ↓
Additional Analysis
    ↓
Validation
```

---

# Example Scenario Types

Challenges may include:

* Brute force authentication
* Password spraying
* Encoded PowerShell
* DNS tunneling
* Credential compromise
* Backdoor account creation

---

# Learning Goal

The challenge system is designed to help users develop practical SOC skills through repeated investigation and analysis.

The goal is to move learners from:

```text
"I know the concept"
        ↓
to
"I can investigate it"
```
