# ✨ SocQuery Lab Features

## Overview

SocQuery Lab combines multiple SOC training workflows into a single browser-based platform.

---

# 📊 Executive SOC Dashboard

Provides high-level visibility into security activity.

Capabilities include:

* Security KPIs
* Event distribution
* Telemetry insights
* MITRE ATT&CK visualization
* Security summaries

---

# 🔍 Search & Reporting

Provides an interactive environment for querying security telemetry.

Capabilities include:

* Query execution
* Field exploration
* Time filtering
* Result analysis
* Execution benchmarks

---

# 🧠 Explain Query

Transforms complex query pipelines into understandable learning steps.

Designed to help users understand:

* Query commands
* Data transformations
* Pipeline execution
* Analytical logic

---

# 🛡️ Detection Engineering

Allows users to create and manage detection rules.

Detection metadata can include:

* Name
* Severity
* Threshold
* ATT&CK mapping
* Status

---

# 🚨 Alert Management

Simulates the SOC alert lifecycle.

Supported statuses:

* New
* Investigating
* False Positive
* Resolved

---

# 🔎 Incident Investigation

Supports investigation workflows through:

* Raw event inspection
* Context analysis
* Event pivoting
* Timeline exploration

---

# 📥 Data Ingestion

Supports local ingestion of:

* CSV
* JSON
* JSONL
* TXT

---

# 🧪 Progressive Challenges

Provides tiered learning exercises.

Levels include:

* Beginner
* Intermediate
* Advanced

---

# 🗺️ MITRE ATT&CK Navigation

Helps users understand the relationship between:

* Security activity
* Detection logic
* ATT&CK tactics
* ATT&CK techniques
