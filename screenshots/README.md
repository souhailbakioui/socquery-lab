# 📸 SocQuery Lab Screenshots

This directory contains official screenshots of the SocQuery Lab platform.

The screenshots are used throughout the main project documentation to demonstrate the platform's key workflows and capabilities.

---

## Screenshot Guidelines

For consistency:

* Use high-resolution screenshots.
* Remove unnecessary browser UI when possible.
* Avoid exposing personal information.
* Use representative training data.
* Keep the SOC interface clearly visible.
* Prefer screenshots that demonstrate a complete workflow.
